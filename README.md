  # 🇪🇸 Анти-ИИ Квен Академия | Полный тренажёр ЕГЭ-2026 по испанскому языку

**English:** *Anti-AI Qwen Academy | Full Spanish EGE-2026 Trainer*

Бесплатный, автономный HTML-тренажёр для подготовки к ЕГЭ по испанскому языку 2026 года. Работает без интернета, без регистрации и без рекламы. Поддерживает переключение интерфейса между русским (RU) и английским (EN) языками.

---

## ✨ Особенности проекта

*   **🌐 Двуязычность (RU/EN):** Полная локализация всех заданий, пояснений и интерфейса. Идеально подходит для международных школ и студентов, изучающих русский язык.
*   **⏱️ Экзаменационный таймер:** Встроенный секундомер с пресетами:
    *   **Экзамен:** 190 минут (формат письменной части ЕГЭ).
    *   **Тренировка:** 60 минут.
    *   Визуальные предупреждения при истечении времени.
*   **🎧 Аудирование и Говорение:**
    *   Поддержка официальных аудиофайлов `audio-es.mp3` (письменная часть) и `audio-es-oral.mp3` (устная часть).
    *   Резервная учебная озвучка через браузерный синтез речи (SpeechSynthesis API), если MP3 файлы недоступны.
*   **📚 Структура экзамена (38+4 задания):**
    *   **Раздел 1 (Аудирование):** Задания 1–9. Соответствие, True/False/Not Stated, интервью.
    *   **Раздел 2 (Чтение):** Задания 10–18. Заголовки, пропуски, понимание текста.
    *   **Раздел 3 (Грамматика и Лексика):** Задания 19–36. Словообразование, выбор слов, грамматические формы.
    *   **Раздел 4 (Письмо):** Задания 37–38. Электронное письмо (100–140 слов) и высказывание по данным (200–250 слов) со счётчиком слов.
    *   **Устная часть:** Задания 1–4. Чтение вслух, вопросы по объявлению, интервью, монолог по фото.
*   **🔒 Полная автономность:** Один HTML-файл. Не требует установки Python, Node.js или подключения к серверам. Работает прямо из браузера (`file:///`).
*   **✅ Чек-лист и План подготовки:** Интерактивный чек-лист из 24 пунктов и детальный план занятий на 25 дней для системной подготовки.

## 🚀 Как использовать

### Способ 1: Локальное использование (Рекомендуется)
1. Скачайте файл `index.html` из этого репозитория.
2. (Опционально) Положите рядом файлы `audio-es.mp3` и `audio-es-oral.mp3`, если они у вас есть. Если нет — приложение автоматически использует встроенные текстовые скрипты для озвучки.
3. Откройте `index.html` двойным щелчком мыши в любом современном браузере (Chrome, Firefox, Edge, Safari).
4. Нажмите кнопку **▶** в правом верхнем углу, чтобы запустить таймер.
5. Переключайте язык кнопкой **RU / EN**.
